# NameBattler

名前からキャラクターを生成して戦う、静的ファイルだけで動くブラウザゲームです。

## 遊び方

`index.html` を直接開くか、任意の静的サーバーでこのフォルダを配信してください。

```powershell
python -m http.server 4173
```

その後、ブラウザで `http://127.0.0.1:4173` を開きます。

## 収録内容

- 名前から固定生成される職業、レベル、能力
- 1人用の固定ステージ進行
- 2人用の名前対戦
- マニュアル操作とオート操作の切り替え
- 戦闘速度の切り替え（0.75倍速、1倍速、1.5倍速、2倍速）
- MPを使う魔法、TPを使う特技、レベルごとの習得
- 画面いっぱいのマス目で選べる魔法・特技
- ダメージ、ミス、会心、能力変化の浮き表示
- 戦闘後のお金と能力の種
- 元の名前に記号を足す名前パターン
- ブラウザ内生成のBGMと効果音
